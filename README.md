## About The Project

Maison Restaurant Management System is a full-stack web application designed to manage restaurant operations, including products, orders, inventory, and sales.

The system provides a customer-facing website for browsing products and placing orders, along with an admin dashboard for managing restaurant operations.

## Technologies Used

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- REST APIs

## Main Features

- Customer product browsing and ordering.
- Shopping cart management.
- Admin authentication.
- Add, update, and delete products (CRUD).
- Product and inventory management.
- Order management.
- Customer information storage.
- Dashboard for monitoring restaurant operations.
